# 08: 실시간 채팅 (WebSocket)

**What to build:** 시청자가 다른 시청자의 채팅 메시지를 새로고침 없이 바로 본다. 방송이 종료되면 채팅 입력이 바로 막힌다.

**Blocked by:** 07 (채팅 보내기)

**Status:** resolved

- [x] 채팅은 Dioxus 서버 함수의 WebSocket으로 주고받고, 별도 실시간 서버는 없다
- [x] 같은 방송을 구독한 둘 중 하나가 보내면 다른 쪽이 받는다 (onair 서비스 테스트로 확인)
- [x] 다른 방송이나 다른 채널의 메시지는 받지 않는다 (테스트로 확인)
- [x] 채널 페이지에 들어오면 최근 50개를 받은 뒤 구독을 시작해, 사이에 빠지는 메시지가 없다
- [x] 방송이 종료되면 구독 쪽에 종료가 전달되고, 채팅 입력이 막힌다
- [x] 브라우저 창 두 개로 실시간 전달을 직접 확인했다
