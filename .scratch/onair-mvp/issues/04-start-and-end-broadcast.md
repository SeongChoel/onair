# 04: 방송 시작과 종료 (영상 없이)

**What to build:** 스트리머가 스튜디오에서 제목을 정해 방송을 시작하고 종료한다. 시청자는 채널 목록과 채널 페이지에서 라이브 중인지와 방송 제목을 본다. 영상은 아직 없다.

**Blocked by:** 03 (채널 만들기와 스튜디오 들어가기)

**Status:** ready-for-agent

- [ ] 스튜디오에서 제목을 입력하고 방송 시작을 누르면 새 방송이 생긴다
- [ ] 제목이 비어 있으면 "{채널 이름}의 방송"이 제목이 된다
- [ ] 진행 중인 방송이 있으면 방송 시작이 거부되고, 스튜디오에서는 방송 종료만 보인다
- [ ] 방송 종료를 누르면 방송에 종료 시각이 기록되고, 다시 시작하면 새 방송이 생긴다
- [ ] 채널 목록에서 라이브 중인 채널이 맨 앞에 LIVE 표시와 방송 제목으로 보인다
- [ ] 채널 페이지에 라이브 중이면 방송 제목, 아니면 "방송 중이 아닙니다"가 보인다
- [ ] 진행 중인 방송이 없을 때 방송 종료는 거부된다
