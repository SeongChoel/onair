# 03: 채널 만들기와 스튜디오 들어가기

**What to build:** 스트리머가 스튜디오에서 채널을 만들고 송출 키와 OBS 서버 주소를 받는다. 송출 키로 스튜디오에 다시 들어가거나 나갈 수 있다.

**Blocked by:** 02 (채널 목록)

**Status:** ready-for-agent

- [ ] 스튜디오에서 채널 이름을 입력해 채널을 만들 수 있고, 만들면 송출 키가 보인다
- [ ] 송출 키는 추측하기 어려운 무작위 문자열이고 고정 접두어가 붙는다
- [ ] 이미 있는 이름이나 빈 이름(앞뒤 공백 제거 후)은 이유와 함께 거부된다
- [ ] 만든 채널의 송출 키가 브라우저에 저장되고, 다시 스튜디오에 오면 바로 채널 관리 화면이 보인다
- [ ] 채널 관리 화면에서 송출 키와 OBS 서버 주소를 보고 복사할 수 있다
- [ ] 송출 키를 입력해 스튜디오에 들어갈 수 있고, 틀린 키는 거부된다
- [ ] 나가기를 누르면 브라우저에 저장된 송출 키가 지워진다
- [ ] 새로 만든 채널이 채널 목록에 나타난다
