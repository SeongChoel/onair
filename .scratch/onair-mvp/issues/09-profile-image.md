# 09: 채널 프로필 이미지

**What to build:** 스트리머가 스튜디오에서 채널 프로필 이미지를 올리면, 채널 목록과 채널 페이지에 그 이미지가 보인다.

**Blocked by:** 03 (채널 만들기와 스튜디오 들어가기)

**Status:** ready-for-agent

- [x] 스튜디오에서 이미지 파일을 올릴 수 있고, 업로드 폴더에 저장되어 채널에 연결된다
- [x] jpg, png, webp만 받으며, 형식은 파일 이름이 아니라 내용으로 판별한다 (테스트로 확인)
- [x] 2MB를 넘는 파일은 이유와 함께 거부된다 (테스트로 확인)
- [x] 새 이미지를 올리면 기존 이미지가 교체되고, 이전 파일은 남지 않는다
- [x] 채널 목록과 채널 페이지에 프로필 이미지가 보이고, 없으면 기본 이미지가 보인다
- [x] 송출 키가 틀리면 업로드가 거부된다
