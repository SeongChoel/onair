# 05: 송출과 시청 (MediaMTX 연동)

**What to build:** 스트리머가 방송 시작 후 OBS나 테스트 송출 스크립트로 송출하면, 시청자가 채널 페이지에서 영상을 본다. 방송이 진행 중이 아니면 송출이 거부된다. 재생 주소에는 송출 키가 드러나지 않는다. ADR-0001을 따른다.

**Blocked by:** 04 (방송 시작과 종료)

**Status:** ready-for-agent

- [x] MediaMTX가 송출·재생 요청마다 onair의 확인 주소를 호출하고, onair의 영상 수신 허락 결과를 따른다
- [x] 송출은 송출 키가 맞고 그 채널에 진행 중인 방송이 있을 때만 허락된다 (방송 시작 전, 종료 후, 틀린 키는 거부, 테스트로 확인)
- [x] 시청자 채널 페이지는 채널 아이디로 된 경로의 HLS를 재생하며, 재생 주소와 페이지 어디에도 송출 키가 없다
- [x] 송출 키 경로를 채널 아이디 경로로 넘기는 방법을 정하고, MediaMTX 설정만으로 안 되면 고른 대안을 명세와 ADR에 기록한다
- [x] 테스트 송출 스크립트가 채널을 받아, 영상 파일 없이 ffmpeg로 테스트 영상과 소리를 그 채널에 반복 송출한다
- [x] OBS 설정 방법(서버 주소, 송출 키 넣는 곳)이 개발 문서에 적혀 있다
- [x] 로컬에서 시드 채널로 방송 시작 → 테스트 송출 → 채널 페이지 재생까지 직접 확인했다
