# 10: 채팅 도배 방지

**What to build:** 시청자가 짧은 시간에 채팅 메시지를 쏟아내지 못하게 한다. 같은 채널에서 같은 닉네임으로 5초 안에 5개까지만 보낼 수 있고, 넘으면 "잠시 후 다시 보내세요"로 거부한다. 로그인이 없으므로 닉네임으로 같은 사람을 구분한다(닉네임을 바꾸면 우회되며, 같은 닉네임을 쓰는 시청자끼리는 한도를 나눠 쓴다). 로그인을 붙이면 계정 기준으로 바꾼다.

**Blocked by:** 07 (채팅 보내기)

**Status:** resolved

- [x] 같은 채널·같은 닉네임으로 5초 안에 6번째 메시지를 보내면 "잠시 후 다시 보내세요"로 거부되고 저장·전달되지 않는다
- [x] 첫 메시지로부터 5초가 지나면 다시 보낼 수 있다
- [x] 다른 닉네임, 다른 채널은 한도가 따로다
- [x] 거부된 메시지는 한도 계산에 들어가지 않는다
- [x] 채널 페이지에서 거부되면 이유가 입력칸 아래에 보이고 입력한 내용은 남아 있다
