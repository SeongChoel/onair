# 07: 채팅 보내기 (닉네임, 최근 50개)

**What to build:** 시청자가 닉네임을 정해 라이브 중인 방송의 채팅에 메시지를 보낸다. 채널 페이지에 들어오면 그 방송의 최근 채팅 메시지 50개가 보인다. 실시간 전달은 08에서 하며, 이 티켓에서는 새로고침하면 새 메시지가 보인다.

**Blocked by:** 04 (방송 시작과 종료)

**Status:** ready-for-agent

- [x] 처음 채팅하려 하면 닉네임을 묻고, 닉네임은 브라우저에 저장된다
- [x] 닉네임을 바꿀 수 있고, 이미 보낸 메시지의 닉네임은 그대로다
- [x] 같은 닉네임을 여러 시청자가 쓸 수 있다
- [x] 메시지를 보내면 닉네임과 함께 저장되고 채팅에 보인다
- [x] 빈 메시지, 500자 초과 메시지, 빈 닉네임, 20자 초과 닉네임은 이유와 함께 거부된다
- [x] 채널 페이지에 들어오면 진행 중인 방송의 최근 채팅 메시지 50개가 오래된 순으로 보인다
- [x] 라이브 중이 아닌 채널에서는 채팅 입력이 막혀 있고, 서비스도 거부한다
- [x] 새 방송의 채팅은 비어 있고, 끝난 방송의 채팅 메시지는 지워지지 않는다 (테스트로 확인)
