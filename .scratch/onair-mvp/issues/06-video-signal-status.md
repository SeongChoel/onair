# 06: 영상 신호 상태 표시

**What to build:** 스트리머는 스튜디오에서 영상 신호가 들어오는지 본다. 시청자는 영상 신호가 없으면 "영상 신호 없음"을 보고, 신호가 돌아오면 새로고침 없이 이어서 본다. 방송이 종료되면 시청 화면이 "방송 중이 아닙니다"로 바뀐다.

**Blocked by:** 05 (송출과 시청)

**Status:** resolved

- [x] onair 서비스가 채널의 영상 신호 상태를 MediaMTX에 물어 돌려준다
- [x] MediaMTX에 묻는 부분을 바꿔 끼울 수 있어서, MediaMTX 없이 테스트할 수 있다
- [x] 스튜디오에 영상 신호 있음/없음이 표시되고 주기적으로 갱신된다
- [x] 방송 중인데 영상 신호가 없으면 시청 화면에 "영상 신호 없음"이 보인다
- [x] 영상 신호가 다시 들어오면 시청 화면이 새로고침 없이 재생을 이어 간다
- [x] 영상 신호가 끊겨도 방송은 자동으로 종료되지 않는다 (테스트로 확인)
- [x] 보고 있던 방송이 종료되면 시청 화면이 "방송 중이 아닙니다"로 바뀐다
