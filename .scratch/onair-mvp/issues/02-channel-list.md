# 02: 채널 목록 (시드 채널 3개)

**What to build:** 시청자가 첫 화면에서 채널 목록을 보고, 채널을 눌러 채널 페이지로 간다. 처음 켜면 테스트 채널 3개가 자동으로 들어가 있다.

**Blocked by:** 01 (개발 환경과 빈 앱 뼈대)

**Status:** ready-for-agent

- [x] 서버 시작 시 스키마가 만들어지고, 채널이 하나도 없으면 테스트 채널 3개가 들어간다
- [x] 테스트 채널의 송출 키는 고정값이고 개발 문서에 적혀 있다
- [x] 첫 화면에 모든 채널이 이름과 함께 보인다
- [x] 프로필 이미지가 없는 채널은 채널 이름 첫 글자로 된 기본 이미지로 보인다
- [x] 채널을 누르면 채널 아이디로 된 주소의 채널 페이지로 가고, 채널 이름이 보인다
- [x] 시청자 쪽 응답에 송출 키가 담기지 않음을 테스트로 확인한다
- [x] SQLite 파일을 지우고 다시 켜면 시드 상태로 돌아간다
